# 大厂高级前端 · AI 面试题准备清单

> 目标：字节 / 阿里 / 腾讯等社招 **高级前端** 面试中，关于 AI 使用与 AI 能力的高频题逐题吃透。  
> 用法：每题按「口述要点 → 追问预案 → 我的案例」准备；勾选表示能稳定讲 3～5 分钟。  
> 相关文档：[AI-Agent学习指南.md](./AI-Agent学习指南.md)（概念与项目自测）、[BAT前端社招准备建议.md](./复习内容总览/第二次系统准备/BAT前端社招准备建议.md)

---

**面试官真正在看的三件事：**

1. **会不会用**——工作流是否具体  
2. **能不能控**——审查、安全、质量有没有门禁  
3. **能不能落地**——Streaming / Agent / 评测 / 成本是否说得清

## 备答策略速查

| 层级 | 怎么答 | 别怎么答 |
|------|--------|----------|
| **P0 必答** | 工作流 + 审查清单 + 1 个翻车案例 | 「我全用 AI 写」 |
| **P1 加分** | Streaming UI / 取消 / 安全 / 状态机 | 只背概念名词 |
| **P2 溢价** | Agent 链路 + 评测 + 成本 + 可观测 | 把玩具 demo 吹成生产系统 |

---

## 建议准备顺序

1. **第 1 轮（2～3 天）**：必杀 8 题，每题口头录一遍或对着镜子讲  
2. **第 2 轮**：第一类 Q1～Q10 全部填完（几乎必问）  
3. **第 3 轮**：第二类 Q11～Q20（有 AI 业务线时高频）  
4. **第 4 轮**：第三类 + 对照《AI-Agent学习指南》第六部分自测  
5. **第 5 轮**：第四、五类扫一遍，软性题对齐《职业规划结论文档》
