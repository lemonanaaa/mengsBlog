# 本次跳槽行动指南

> 配合《职业规划结论文档》使用。  
> 目标：社招拿下 **高级 / 资深前端** offer，同步为 **AI 应用 / Agent** 方向打底。

---

## 一、先决条件（开工前先具备）

这些是「可以开始投递」的最低门槛，缺一项就优先补一项。

### 1.1 材料与叙事

| 先决条件 | 完成标准 |
|----------|----------|
| **简历定稿** | 2～3 个核心项目，每条具备：背景 → 你的动作 → 难点 → 结果 |
| **项目故事库** | 每个核心项目能连续讲 **20 分钟**，经得起追问 |
| **数据口径** | 简历上的数字都能解释统计口径；不确定的改定性表述 |
| **自我介绍** | 1 分钟版 + 3 分钟版，突出：复杂 C 端、工程化、方案主导 |
| **离职 / 动机话术** | 为什么看机会、为什么选高级前端、为什么关注 AI 业务 |

### 1.2 能力与经验（你已有，需整理成「可讲」）

| 先决条件 | 你的现状（携程 4 年） | 面试时要能讲清 |
|----------|----------------------|----------------|
| **复杂业务交付** | 旅游 BG、订单/退款等 C 端链路 | 模块边界、协作对象、你负责什么 |
| **性能 / 稳定性** | 线上优化、指标改善 | 优化前后数据、手段、风险 |
| **工程化** | 构建、规范、工具链 | 你推动过什么、解决了什么痛点 |
| **React 主栈** | 日常开发 + 升级类项目 | 版本、状态管理、组件设计取舍 |

### 1.3 环境与节奏

| 先决条件 | 说明 |
|----------|------|
| **固定准备时间** | 工作日每天 1.5～2h，周末每天 3～4h（可按实际情况调整） |
| **投递渠道** | 内推名单、Boss、猎头等至少 2 个渠道就绪 |
| **目标公司清单** | 10～20 家，标注：AI 业务、团队规模、内推人 |
| **面试记录表** | 用于记录每轮问题、薄弱点、待补知识点 |

### 1.4 AI 方向（辅助先决，非阻塞投递）

| 先决条件 | 完成标准 |
|----------|----------|
| **1 个 Agent 小项目** | 能 demo、能讲架构、能说明技术选型 |
| **基础概念** | 能口头解释：LLM API、Prompt、Tool Calling、RAG |
| **简历一句话** | 「业余探索 AI 应用，完成 XXX 小项目」 |

## 二、整个跳槽过程：分阶段学什么

```
准备期 → 投递期 → 密集面试期 → Offer 决策期 → 入职前
  │         │           │              │           │
  └─ 知识+简历 └─ 维持+复盘 └─ 冲刺+查漏 └─ 选公司  └─ 交接+预习
```

## 三、准备期（投递前 2～4 周）

**目标：** 简历能投、基础题能答、项目能深挖。

### 3.1 第一优先级：简历项目（占 40% 时间）

| 学习内容 | 学到什么程度 | 产出 |
|----------|--------------|------|
| **项目复盘** | 每个项目整理：背景、职责边界、3 个技术难点、方案对比、结果指标 | 项目故事文档 |
| **高级叙事** | 从「做了什么页面」转为「定了什么方案、为什么、影响是什么」 | 简历改写 |
| **追问预演** | 每个项目准备 10 个可能被追问的问题 | Q&A 清单 |

**重点复习项目类型（结合你的背景）：**

- 复杂 C 端链路（多状态、多角色、异常流）
- 性能优化（首屏、包体积、长列表、监控）
- 工程化 / 升级类（React 升级、规范、工具链）
- 有数据结果的项目（转化率、错误率、人力节省等）

### 3.2 第二优先级：面试硬知识（占 40% 时间）

按《前端面试知识大纲》的 **P0** 闭环：

| 模块 | 核心考点 | 学习产出 |
|------|----------|----------|
| **JavaScript** | Event Loop、Promise、闭包、this、原型、手写题 | 能白板写：防抖节流、深拷贝、并发调度 |
| **React** | Fiber 动机、Render/Commit、Hooks 原理、Diff/key、性能优化 | 能讲清 3 个你项目里的 React 技术决策 |
| **性能 / 工程化** | 首屏、包体积、监控、Webpack/Vite、CI | 结合项目各举 1 个真实案例 |
| **算法** | 中等题：数组、哈希、双指针、滑窗、链表、树、LRU | 每天 1～2 题，保持手感 |

### 3.3 第三优先级：AI 小项目（占 20% 时间）

| 学习内容 | 学到什么程度 | 产出 |
|----------|--------------|------|
| LLM API 调用 | 能完成多轮对话 + 流式输出 | 可运行的 chat demo |
| Tool Calling | 定义 1～2 个工具并完成调用闭环 | 如：查 Todo、搜博客 |
| RAG 基础 | 文档切块 + 向量检索 + 问答 | 基于你博客/简历的问答 |
| 项目包装 | 能画架构图、讲数据流 | README + 简历一行描述 |

**推荐项目：** mengsblog AI 助手（RAG 简历/博客 + 工具调用 Todo）

## 四、投递期（第 1～2 周）

**目标：** 开始投递，用真实反馈校准准备方向。

### 4.1 继续学

| 方向 | 内容 | 频率 |
|------|------|------|
| **维持手感** | 算法 1 题/天，手写 1 题/周 | 每天 |
| **P1 补强** | 网络缓存、跨域、安全、TS 泛型 | 按 JD 要求补 |
| **场景题** | 搜索联想、虚拟列表、大文件上传、埋点 | 每周 2 个 |
| **AI 项目** | 打磨 demo、补日志/错误处理 | 每周固定 3h |

### 4.2 同步做

| 动作 | 说明 |
|------|------|
| **投递** | 先投 3～5 家练手，再投目标公司 |
| **筛公司** | 对照职业规划：AI 业务、前端全链路、内部转岗 |
| **记录** | 每投一家记录 JD 关键词，反向补简历 |

---

## 五、密集面试期

**目标：** 根据面经快速查漏，稳定发挥。

### 5.1 每场面试后（24h 内）

| 动作 | 说明 |
|------|------|
| **复盘** | 记录被问到的题、答不好的点 |
| **补漏** | 薄弱点当天或次日专门学 1～2h |
| **更新故事库** | 新想到的案例补充进项目叙事 |

### 5.2 按面试轮次侧重

| 轮次 | 重点准备 |
|------|----------|
| **HR / 初面** | 动机、离职原因、薪资预期、项目概述 |
| **技术面** | 项目深挖、JS/React、算法、场景设计 |
| **交叉 / 二面** | 系统设计、方案权衡、跨团队协作、技术规划 |
| **Leader 面** | 业务理解、ownership、稳定性与风险意识 |

### 5.3 持续维持

- 算法：隔天 1 题
- 项目故事：每天过 1 个项目
- AI 项目：保持可 demo 状态，被问到能讲 3 分钟

---

## 六、Offer 决策期

**目标：** 选对「高级前端 + AI 延伸空间」的组合。

### 6.1 决策维度

| 维度 | 看什么 |
|------|--------|
| **职级 title** | 是否达到高级 / 资深 |
| **业务复杂度** | C 端核心链路 vs 边缘需求 |
| **AI 业务** | 有没有 AI 产品线、平台团队 |
| **团队氛围** | 技术深度、协作方式、成长空间 |
| **前端角色** | 能否参与全链路（API、工具、评测） |

### 6.2 此阶段学习

- 了解目标公司业务与产品（官网、技术博客、开源）
- 准备「入职 90 天计划」口述版
- 补目标公司技术栈相关的 1～2 个知识点

---

## 七、入职前（Gap 期）

**目标：** 平稳交接，为入职后的 AI 协作预热。

| 动作 | 说明 |
|------|------|
| **工作交接** | 文档化、知识转移，维护职业口碑 |
| **休息调整** | 避免空窗期完全脱节 |
| **AI 预习** | 了解目标公司 AI 产品；继续维护 Agent 小项目 |
| **前端保温** | 每周做 1～2 道算法 / 读 1 篇技术文章 |

## 八、知识清单总表（按优先级）

### P0：必须闭环（投递前完成）

- [ ] 2～3 个项目故事，每个能讲 20 分钟
- [ ] JS：Event Loop、Promise、闭包、this、原型
- [ ] 手写：防抖节流、深拷贝、并发调度、LRU
- [ ] React：Fiber、Hooks 原理、Diff、性能优化手段
- [ ] 性能：首屏优化、包体积、监控方案（结合项目）
- [ ] 工程化：Webpack/Vite、CI、规范（结合项目）
- [ ] 算法：中等题 30～50 道
- [ ] 简历定稿 + 自我介绍 + 动机话术
- [ ] Agent 小项目可 demo

### P1：高频补强（投递后持续）

- [ ] 网络：缓存、跨域、HTTPS、HTTP/2
- [ ] 安全：XSS、CSRF、JWT
- [ ] TypeScript：泛型、工具类型
- [ ] 场景题：虚拟列表、搜索联想、大文件上传
- [ ] 开放设计题：如何设计 XX 系统的前端架构

### P2：AI 应用（并行，服务长远）

- [ ] LLM API + Streaming
- [ ] Prompt 设计与迭代
- [ ] Function / Tool Calling
- [ ] RAG：切块、Embedding、向量检索
- [ ] Agent 基础架构：ReAct loop
- [ ] 日志、Eval、成本意识

### P3：了解即可（JD 提到再深入）

- [ ] Vue3 核心差异
- [ ] 微前端、模块联邦
- [ ] Node.js 中间层
- [ ] 深度学习 / 模型训练（长远可选）

## 十、自检：可以开始投递了吗？

全部打勾即可开投：

- [ ] 简历上 2～3 个项目都能深挖 20 分钟
- [ ] 自我介绍 1 分钟版流畅
- [ ] JS Event Loop + Promise 能讲清楚
- [ ] React Fiber + Hooks 能结合项目讲
- [ ] 手写题：防抖、深拷贝、LRU 能写出来
- [ ] 算法中等题有一定题量积累
- [ ] 目标公司清单 ≥ 10 家
- [ ] Agent 小项目能 demo（加分项，建议有）

## 十一、与长远 AI Agent 方向的衔接

本次跳槽学的东西，和入职后的路径是这样对应的：

| 本次学到 | 入职后用在 |
|----------|------------|
| 高级前端面试能力 | 日常工作交付、职级站稳 |
| AI 产品交互（Streaming UI 等） | AI 产品前端需求 |
| LLM API + Tool Calling | 协作后端 / AI 应用同学 |
| RAG 小项目 | 内部分享、转岗案例 |
| 工程化 + 评测意识 | Agent 链路的产品化与稳定性 |
