# 职业规划 — 本次跳槽核心文档

> 整理自 2026-06-29 对话，v4 精简版。  
> 用途：指导**这一次社招**，并与长期 AI Agent 方向对齐。

---

## 一、核心结论

| 维度 | 结论 |
|------|------|
| **本次目标** | 通过社招拿到 **高级 / 资深前端** offer，完成职级跃迁 |
| **能力标准** | 能独立负责模块或小团队，讲清方案、扛交付、带协作 |
| **行业策略** | 稳前端职级，同步叠加 AI 能力 |
| **公司选择** | 优先有 **AI 业务** 的公司，为 1～2 年后转 AI 应用留口子 |
| **长远方向** | 高级前端 → AI 产品前端 → **AI 应用 / Agent 工程** |

---

## 二、职级与能力目标

### 2.1 目标职级

| 档位 | 含义 |
|------|------|
| **底线** | 高级前端 — 社招达标，具备独立交付能力 |
| **主目标** | 资深前端 — 能负责复杂模块，有方案主导权 |
| **冲刺** | 大厂资深 / 核心业务岗 — 复杂系统、高协作、面试表现突出 |

### 2.2 能力期待（3～7 年经验）

- 从「能执行」升级到「能负责」：方案、模块、协作、风险意识
- 30 岁是窗口期，也是区间：**28～32 岁任一年达到高级职级均可**
- 选 offer 时重点看：**职级 title、业务复杂度、团队技术氛围**

---

## 三、本次主攻方向

**主战线：社招拿高级前端 offer。**

达成后可获得：

- 职级跃迁
- 进入 AI 公司的入场门票
- 简历叙事连续
- 为后续内部转岗积累筹码

**能力延伸方向：**

| 方向 | 定位 |
|------|------|
| **高级前端** | 本次跳槽主目标 |
| **Agent / AI 应用**（编排、RAG、工具调用、产品化） | 中长期延伸，适合叠加在前端能力之上 |

**前端能力重点：**

- 复杂 C 端、性能与稳定性、工程化、基建
- AI 产品体验与交互

---

## 四、选公司：看什么

- 主业或重要条线含 **AI 产品、Copilot、智能客服、自动化**
- 有 AI 平台 / 应用团队，前端能参与 **全链路**
- 文化上允许 **内部转岗**

**面试时可主动问：**

- 团队有没有 AI / Agent 相关需求？
- 内部转岗先例多不多？
- 前端是否会参与 Prompt 迭代、工具接入、评测？

---

## 五、简历与面试：怎么讲

### 5.1 简历 / 项目

按 **高级前端** 标准组织，重点突出：

- **复杂业务**：C 端核心链路、多角色、多状态
- **性能与稳定性**：指标、优化手段、线上结果
- **工程化**：规范、基建、协作效率
- **方案主导**：你定过什么方案、为什么、结果如何

### 5.2 AI 部分（辅助）

- 业余保持：**1 个能讲的 Agent 小项目**（LLM API + 工具调用 / RAG）
- 简历定位：**「有 AI 应用探索的高级前端」**
- 面试话术：目标是高级前端；希望进入有 AI 业务的公司，从 AI 产品前端逐步参与应用链路

---

## 六、行动优先级

```
1. 社招面试 → 高级前端 offer
2. 筛公司 → 有 AI 业务 + 前端能碰全链路
3. 简历 / 项目 → 按高级标准重写叙事
4. AI / Agent → 业余并行，完成一个小项目
```

---

## 七、长远路径（入职后推进）

```
本次跳槽     高级 / 资深前端（有 AI 业务的公司）
    ↓ 0～6 个月
协作 AI 需求，从 UI 接到 API / 工具 / 评测
    ↓ 6～18 个月
AI 应用工程师 / Agent 工程师（偏工程）
```

**入职后可做：**

1. 申请换到或协作 AI 相关需求
2. 自建小闭环：聊天 + 工具调用 + 日志 / 评测，内部分享
3. 跟 AI 应用 / 后端同学绑项目
4. 半年到一年后再谈转岗，带着 **线上案例**

---

## 八、决策逻辑链

```
高级 + 工程化 + AI 落地，是当前最有价值的前端组合
        ↓
本次目标：高级 / 资深前端，完成职级跃迁
        ↓
本次策略：冲高级前端 → 选有 AI 业务的公司 → 简历按高级标准讲
        ↓
并行学习：LLM API、工具调用，做 1 个 Agent 小项目
        ↓
长远路径：入职后 1～2 年，从 AI 产品前端靠向 AI 应用 / Agent
        ↓
当务之急：社招拿 offer，准备收敛到面试与投递
```
